# Student background and course direction

You are a senior frontend engineer with React, Next.js, TypeScript, complex application architecture, production monitoring, and performance experience. The course assumes programming fluency and does not spend lessons on basic JavaScript or introductory React.

The destination is practical senior full-stack ownership: define a contract, implement a backend, choose and query data structures, reason about competing operations, deploy a change, observe failures, and recover safely.

## Working context

- Backend: Python and FastAPI, with REST integration from TypeScript/Next.js.
- Persistence: PostgreSQL and PostGIS; Redis and messaging systems when their trade-offs justify them.
- Operations: Railway, GitHub Actions, Docker, DNS, TLS, environment configuration, logging, and Datadog-style telemetry.
- Recurring project: StopAround, a route-aware fuel-stop recommendation application. Independent examples prevent the course from becoming a single-product tutorial.

## Where the teaching goes deeper

Database internals, query planning, transactions, MVCC and isolation; concurrency, locks and retries; distributed consistency and coordination; resource limits, capacity and scale; security, schema migration, deployment, observability, and incident recovery.

Each lesson should connect explanations to a mechanism, a failure case, and an action you can perform. Interview practice remains useful, but an eloquent architecture diagram is not sufficient evidence that you can implement and operate the design.

## Learning conditions

Work in small, complete batches. Preserve every lesson in the original 98-lesson syllabus and the eight practical implementation labs. The HTML reader should support studying after a workday: large text, clear hierarchy, short lines, restrained colors, and minimal visual noise. Keep the full prose and solutions available offline.
